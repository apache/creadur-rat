# Creadur RAT Migration Guide - Release 0.19

Release 0.19 is an intermediate release as we are working on big architectural changes within the 1.0.0 feature development.

## General

* [RAT-592](https://issues.apache.org/jira/browse/RAT-592) fixed the classification of BAT files/shell scripts, so that they are handled as standard files during RAT runs and need license headers.

### Adding license headers to Markdown and AsciiDoc

[RAT-517](https://issues.apache.org/jira/browse/RAT-517) improves license header insertion for documentation files:

* Markdown files keep their YAML front matter at the beginning of the file. RAT inserts the license as an HTML comment after the front matter, so site generators can still read the metadata. Both `---` and `...` closing delimiters are supported. Unterminated front matter causes an error and leaves the original file unchanged.
* AsciiDoc files (`.adoc`, `.asciidoc` and `.asc`) now support license insertion. RAT places the license in a `////` block comment after the document title and header metadata. Files without a document header receive the license at the beginning.
* Files without a recognized extension can also receive license headers when RAT detects a supported Markdown, AsciiDoc, XML or HTML content type.

These changes apply when you use RAT to add license headers; normal license checking is unchanged. No configuration changes are required.
